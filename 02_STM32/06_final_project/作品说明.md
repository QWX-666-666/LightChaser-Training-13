# 基于 STM32 的循迹蓝牙遥控小车

## 1. 功能概述

基于 STM32F103C8T6 的双模式小车：**四路红外循迹**与**蓝牙遥控**，两个按键可随时切换，切换瞬间自动停车。

主要功能：

1. 四路红外循迹：四个传感器加权成一个连续偏差（-4~+4），用转向 PID 输出左右轮差速，直道稳定、弯道平滑。
2. 急弯自动降速：偏差 ≥2（急弯）时把两轮占空比限制在 32%，直道不受影响，避免高速冲线。
3. 丢线自动找回：四个传感器全丢时不停车，按最后一次偏差方向原地转，直到重新压线。
4. 蓝牙遥控：JDY-31（USART3，9600，DMA + 空闲中断）接收 0x00~0x06 七条指令，控制前进/左转/右转/后退/刹车/加速。
5. 双按键模式切换：PA6 进循迹、PB1 进蓝牙，切换瞬间强制停车。

## 2. 硬件清单

1. STM32 开发板：STM32F103C8T6 * 1
2. 双路电机驱动板：AT8236-6A（TK-MD320A V2.0）* 1
3. 直流减速电机：MC520 * 2
4. 四路红外循迹模块 * 1
5. 蓝牙串口模块：JDY-31-SPP * 1
6. 轻触按键 * 2
7. 12V 锂电池 * 1
8. 车轮、车架、面包板及杜邦线若干

## 4. 实现思路

**主循环 / 状态机**

- `flag` 是"模式"，由两个 EXTI 中断写入：`1 = 循迹`、`2 = 蓝牙`、`0 = 待机`。
- 主循环 `switch (flag)`：
  - `case 1`：读 4 路传感器 → 加权偏差 → 转向 PID → 差速 → 限幅 → 输出，周期 10ms。
  - `case 2`：等 `cmd_flag`（UART 空闲中断置位）→ 解析第一个字节 → 执行对应动作。
- 两个 EXTI 中断里**先停车再改模式**，保证切换无冲击。
- 中断只做"置标志/置位"，业务全部在主循环，符合"中断要短"的原则。

**通信协议**（蓝牙，9600 8N1，十六进制发送）

| 指令 | 含义 |
|---|---|
| `00` | 滑行停车 |
| `01` | 前进 |
| `02` | 左转 |
| `03` | 右转 |
| `04` | 后退 |
| `05` | 刹车 |
| `06` | 加速前进 |

## 6. 遇到的问题与解决

问题 1：循迹直道左右摆，四档 if/else 只有 5 种固定输出

解决：改成加权偏差 + 转向 PID，连续调节差速

问题 2：模式切换后按键失灵，flag 没加 volatile，被编译器优化

解决：声明改为 `volatile uint32_t flag`

## 7. 测试结果

- **直道**：25~28% 占空比，10 秒内不跑偏，无明显左右摆。
- **弯道**：R≥15cm 的弯可稳定通过；急弯限速 32% 后不再冲线。
- **丢线**：人为把车推出赛道，能在 1~2 秒内原地转回线上（原地转不前进）。
- **蓝牙**：手机 JDY-31-SPP，HEX 发送 01~06，响应即时，无丢帧。
- **模式切换**：行驶中按另一个键，车立即停住并切入新模式。

缺陷：

1. 没有编码器，**车速受电池电压影响**（电量低时整体变慢），未做速度闭环。
2. 没有电压检测，低电量只能靠观察。

## 8. 演示说明

上电后操作顺序：

1. 上电，车静止（flag=0，待机状态）。
2. 按 PA6 键 → 进入循迹模式（板载 LED 亮），把车放在赛道黑线上，车自动沿线行驶。
3. 行驶中按 PB1 键 → 立即停车，进入蓝牙模式。
4. 手机打开蓝牙串口 APP，发送 `01` 前进 / `02` 左转 / `03` 右转 / `04` 后退 / `05` 刹车 / `06` 加速。
5. 再按 PA6 可随时切回循迹。
